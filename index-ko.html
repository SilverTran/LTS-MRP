1단계: 초기 기초 코드 설정

1. 기초 마스터 설정 (CONFIG)

📁 메뉴: CONFIG ▶ Buyer / Supplier / Consignee / Exchange / Code / Location
1. CONFIG 내 6개 화면은 무엇을 입력하나요?

BOM, 계약 또는 발주를 진행하기 전에 아래 6개 화면에서 회사 표준 기초 데이터를 먼저 등록합니다:

✅ 화면별 입력 항목 및 작업 방법:
  • 1. Buyer:
    CONFIG ▶ Buyer (/mrp/config/buyer): 고객사명(예: Buyer-001), 주소, 연락처, 담당자 입력. 초록색 + Add 클릭 ➔ 저장.
  • 2. Supplier:
    CONFIG ▶ Matl. supplier (/mrp/config/matl-supplier): 원부자재 공급업체(예: Supplier-001) 등록. + Add 클릭 ➔ 저장.
  • 3. Consignee:
    CONFIG ▶ Matl. consignee (/mrp/config/matl-consignee): 발주서(PO)에 인쇄될 인수처 법인명 등록(예: BETHELVINA CO.,LTD).
  • 4. Exchange:
    CONFIG ▶ Exchange (/mrp/config/exchange): 통화별 환율(USD, VND, KRW, CNY...) 입력 후 초록색 APPLY 클릭.
  • 5. Code:
    CONFIG ▶ Code (/mrp/config/code): 한 화면에 6개 코드표가 있습니다: R/M Category, Unit, MA #, Color code-Item, Color code-Material, Style code(우측 하단). 각 표의 + ADD(또는 엑셀 ⬇ TEM / ⬆ UP)로 등록합니다.
  • 6. Location:
    CONFIG ▶ Location (/mrp/config/location): 창고 및 공장 위치 코드 등록(예: Factory01-Material-T001, Factory01-Material-T002).
🖥️ Config › Code 전체 화면 (6개 기초 코드표) 우측 하단 Style code 표에서 + ADD를 눌러 BOM 생성 전 스타일 코드와 이름을 먼저 등록하세요
💬 챗봇 질문: Config › Code 6개 표 상세 보기
2단계: 원부자재 마스터 등록

2. 자재 마스터 (Material Master)

📁 메뉴: INVENTORY CONTROL ▶ Material Master
2. Material Master (/mrp/inventory-control/material-master)

BOM과 발주에 사용할 개별 원부자재 마스터 정보를 등록합니다: Supplier, Category(FABRIC, MESH, PACKING), MA #, Name, Color, Unit, Unit Price, Currency, Spec.

✅ 자재 등록 방법:
  • 방법 1:
    웹에서 개별 등록: 초록색 + Create 클릭 ➔ 공급사, 카테고리, MA#, 자재명, 색상, 단위, 단가, 통화 입력 후 저장. 시스템이 코드를 자동 채번합니다(FAB00000001, MES00000001, PAK00000001).
  • 방법 2:
    엑셀 일괄 등록: 주황색 Template 다운로드 ➔ Config › Code 기준에 맞춰 작성 ➔ Import로 업로드.
🖥️ Material Master 목록 화면 예시: 등록된 5개 자재 (FAB00000001, FAB00000002, MES00000001, MES00000002, PAK00000001)
3단계: 기술 BOM 작성

3 & 4. BOM List & BOM Manage

📁 메뉴: BOM DATA ▶ List / Manage
3. BOM List (/mrp/bom-data/list)

신규 BOM 생성(Buyer, Style code, Revision 예: v0.1 선택), 기존 BOM 복사(COPY) 및 수정 잠금/해제(LOCK / UNLOCK)를 수행합니다.

✅ 작업 순서:
  • 1단계:
    신규 생성 또는 복사: 초록색 + Create new BOM 클릭 ➔ GENERATE NEW BOM 팝업에서 BUYER(Buyer-001), STYLE CODE(Stl001), REVISION(v0.1) 입력 후 GENERATE 클릭.
    ⚠️ 목록에 바이어나 스타일이 보이지 않으면 먼저 CONFIG › Code(Style code 표) 또는 CONFIG › Buyer에서 등록하세요!
  • 2단계:
    생성된 BOM 행의 초록색 MANAGE를 눌러 Bom › Manage로 이동합니다.
  • 3단계:
    작성 완료 후 Bom › List에서 행을 체크하고 빨간색 LOCK을 눌러 오수정을 방지하세요(수정 시 UNLOCK).
🖥️ BOM Data › List 화면 등록된 BOM 목록(Stl001, Stl002)과 MANAGE, COPY 버튼
🖥️ GENERATE NEW BOM 팝업 (+ Create new BOM) BUYER, STYLE CODE, REVISION 선택 후 GENERATE 클릭
4. BOM Manage (/mrp/bom-data/manage)

제품 1개당 필요한 원부자재와 소요량을 입력합니다: 제품 색상(Color option), 자재 그룹(Group#1), 자재 코드(SEL), 색상 지정(개별 색상 또는 공용 COMMON), 재단 치수(L × W).

✅ 작업 순서:
  • 1단계:
    파란색 Basic info 클릭 ➔ Manage 모드 확인 후 Color option에 제품 색상 추가(Black-001, White-001).
  • 2단계:
    첫 열 헤더의 Add GP로 Group#1 생성 후 + 버튼으로 자재 행 추가.
  • 3단계:
    COLOR CODE 열에서 체크(☑) = COLOR 모드(색상별 분리 배정), 체크 해제(☐) = COMMON 모드(전 색상 공통 1행 적용)를 선택한 뒤 R/M CODE의 SEL 버튼으로 자재를 선택합니다.
  • 4단계:
    우측 영역에서 재단 부위(Part-1 > Piece-1)와 L × W를 입력하면 즉시 자동 저장됩니다.
🖥️ BOM Manage — Basic info 팝업 Manage 모드, 색상 옵션(Color option) 및 담당자(PIC) 설정
🖥️ BOM Manage — 좌측 영역 (자재 그룹, 색상 코드, 자재 코드) 예시 Stl001: Group#1 내 원단/메쉬/부자재 색상별 및 COMMON 배정
🖥️ BOM Manage — 우측 영역 (재단 치수 L × W 및 총 소요량) 1개당 소요량 자동 계산 결과
4단계: 고객 계약 및 주문 입력

5. 계약 관리 (Contract Status › Active)

📁 메뉴: CONTRACT STATUS ▶ Active
5. Contract › Active (/mrp/contract-status/active)

고객 신규 계약(Contract #, Buyer, PO #, 주문일/선적일, Style code, 색상별 PO Qty, 공임, FOB 단가)을 입력하고 BOM을 연결합니다.

✅ 계약 등록 5단계:
  • 1단계:
    초록색 + Add CONTRACT(수정 시 ✎ Contract-001) 클릭하여 MANAGE ORDER 창 열기.
  • 2단계:
    Contract #(Contract-001) 입력, Buyer(Buyer-001) 선택 후 + Add PO 클릭.
  • 3단계:
    PO #(PO 1), PO date, Target ship date 입력 후 + Add Style 클릭.
  • 4단계:
    Style code(Stl001), Season, Labor cost, FOB 입력 후 +를 눌러 색상(Black-001, White-001) 및 PO Qty 입력.
  • 5단계:
    BOM 버튼이 초록색(Match)인지 확인 후 하단 SAVE 클릭.
🖥️ Contract Status › Active 목록 화면 예시: BOM이 초록색 Match로 연결된 Contract-001 및 Contract-002
🖥️ MANAGE ORDER 입력 팝업 (+ Add CONTRACT) 계약, PO, 스타일, 색상별 수량 및 BOM 매칭 설정 화면
5단계: MRP 소요량 산출 및 자재 발주

6 & 7. Purchase Order (발주) & Mat PO status (조회)

📁 메뉴: INVENTORY CONTROL ▶ Purchase Order / Mat PO status
6. Purchase Order (/mrp/inventory-control/purchase-order)

계약별 자재 소요량 산출 및 발주서(PO-R-...) 발행 화면입니다: ② LOSS %, ② ASSIGN, ① ORDER QTY, ③ UNIT PRICE, CONSIGNEE, RM PO DATE / RM ETA 입력 후 상태를 STANDBY ➔ ORDERED로 변경합니다.

✅ 자재 발주(PO) 확정 5단계:
  • 1단계:
    계약 선택: CONT #(Contract-001) 선택. CONS.(BOM)(AFTER)에 빨간 숫자(14400, 2400, 300)가 있으면 체크박스 선택 후 초록색 UPDATE 클릭.
  • 2단계:
    로스율 입력: ② LOSS % 숫자 클릭(또는 체크 후 SET)으로 생산 로스(%) 반영.
  • 3단계:
    MAKE PO(신규) 또는 ADD(기존 PO 병합): SUPPLIER 열에서 동일 공급업체 자재를 체크하고 MAKE PO 클릭 시 PO-R-YYMMDD-XXX 생성.
  • 4단계:
    수량·단가·납기 확인: 우측 Ⓔ MATERIAL PURCHASE ORDER에서 ORDER QTY, UNIT PRICE, CONSIGNEE, RM PO DATE, RM ETA 확인.
  • 5단계:
    ⚠️ 필수 — STANDBY ➔ ORDERED 전환: 맨 오른쪽 STATUS 컬럼에서 STANDBY(또는 INFO)를 클릭해 ORDERED로 변경 후 APPLY 클릭. 그래야 Income status에서 입고가 가능합니다!
🖥️ Purchase Order (Contract-001) - 파트 1: 자재 정보, BOM 소요량 & 전체 소요량 MATERIAL INFORMATION, Ⓑ BOM CONSUMPTION (CONS.(BOM)(AFTER)의 빨간 숫자 14400, 2400, 300) 및 Ⓒ GLOBAL PO QTY 표시
🖥️ Purchase Order (Contract-001) - 파트 2: Ⓔ MATERIAL PURCHASE ORDER & Ⓕ DELIVERY 발주 수량(7200, 1200, 1000, 200), 단가(1, 1.5), 금액 AMOUNT(18000 & 2400 USD), 발주일(2026/11/16) 및 STATUS(MATERIAL) 표시
🖥️ Purchase Order (Contract-002) - 발주 생성 전 상태 (MAKE PO 클릭 전) 각 행에 ADD 버튼과 SUPPLIER 체크박스가 표시되어 공급사별로 묶어 MAKE PO 가능
7. Mat PO status — 발주 진행 현황 조회 전용 (/mrp/inventory-control/mat-po-status)

📌 용도: 발행된 모든 자재 발주서(PO-R-...)의 상태(STATUS), 총액(AMOUNT), 발주량(① ORDER), 입고량(② W/H IN), 미입고 잔량(①-② BALANCE)을 조회합니다. 수정이 필요하면 Manage PO Group 버튼을 클릭하세요.

🖥️ Mat PO status 화면 ORDERED 상태의 PO-R-261116-001 ($18,000) 및 PO-R-261116-002 ($2,400)
6단계: 창고 입고, 출고 및 재고 조회

8, 9 & 10. Income status, Outgo status & Inventory

📁 메뉴: INVENTORY CONTROL ▶ Income / Outgo / Inventory
8. Income status — 자재 입고 (/mrp/inventory-control/income-status)

공급업체로부터 자재가 입고될 때 입고 엑셀 파일을 업로드합니다(3번째 행부터 입력: DATE-NO YYYY/MM/DD-SN, SUPPLIER, LOCATION, CONTRACT #, CODE, QTY, UNIT, PRICE, AMOUNT, CURRENCY, BUYER, DEBIT, MA #, INSPECTION YYYY.MM.DD).

✅ 자재 입고 4단계:
  • 1단계:
    Purchase Order에서 해당 PO 상태가 ORDERED인지 확인합니다.
  • 2단계:
    주황색 TEMPLATE을 눌러 표준 엑셀 양식을 내려받고 3행부터 입력합니다.
  • 3단계:
    파란색 UPLOAD EXCEL을 눌러 파일을 올리면 시스템이 MATL PO #를 자동 매칭합니다.
  • 4단계:
    • ERROR: 0(노란색 WARNING 예: [WPO]는 저장 가능) 확인 후 초록색 ✔ APPLY INCOME ➔ YES 클릭.
🖥️ Income status 엑셀 업로드 결과 (Contract-001 자재 5건) 실제 예시: • ERROR: 0 • WARNING: 1 (4행 [WPO]Buyer-002 경고), MATL PO # 자동 매칭 완료 — ✔ APPLY INCOME 클릭 대기 상태
9. Outgo status — 자재 출고 (/mrp/inventory-control/outgo-status)

생산 현장으로 자재를 불출할 때 출고 엑셀 파일을 업로드합니다(3행부터 입력; DATE-NO는 2자리 연도 YY/MM/DD-SN, 출고처 FROM 및 인수처 TO 포함).

✅ 자재 출고 3단계:
  • 1단계:
    주황색 TEMPLATE을 눌러 출고 표준 양식을 받아 3행부터 입력합니다.
  • 2단계:
    파란색 UPLOAD EXCEL로 파일을 업로드합니다.
  • 3단계:
    • ERROR: 0 확인 후 초록색 ✔ APPLY OUTGO ➔ YES 클릭.
🖥️ Outgo status 엑셀 업로드 결과 (Contract-001 출고 5건) 실제 예시: • ERROR: 0 • WARNING: 2 ([WPO]), 원단 2000 YDS / 메쉬 400·300 MET / 포장 100 PCS 불출 — ✔ APPLY OUTGO 클릭 대기
10. Inventory — 원부자재 재고 조회 (/mrp/inventory-control/inventory)

📌 용도: 실시간 자재 재고(IN, IN BALANCE, OUT, INVENTORY)를 조회합니다. 기본 필터는 NOT ZERO이며 전체 보기 시 SHOW ALL ➔ 🔍 Refresh를 누르세요. HISTORY로 수불 내역을 보거나 D/L XLS by BUYER / MA#로 엑셀 출력할 수 있습니다.

🖥️ 입고 및 출고 완료 후 Inventory 화면 (NOT ZERO 필터) 실제 예시 (Contract-001): 입고 IN (5000, 5000, 1000, 800, 200), 미입고 IN BALANCE (2200, 2200, 200, 200, 0), 출고 OUT (4200, 4200, 600, 500, 100)
7단계: 완제품 포장, 선적 및 재고

11 & 12. Shipment (선적) & Stock (완제품 재고)

📁 메뉴: CONTRACT STATUS ▶ Shipment & Stock
11. Shipment (/mrp/buyer-order/shipment)

완제품 포장(② PACKED), 실사(④ PHYSICAL) 및 일자별 선적 출하(③ SHIPPED) 수량을 입력합니다.

✅ 포장 및 선적 입력 4단계:
  • 1단계:
    BUYER와 CONTRACT #를 선택한 뒤 초록색 APPLY 클릭.
  • 2단계:
    ② PACKED 열의 ✎ 클릭 ➔ 포장 일자 및 수량 입력 후 저장.
  • 3단계:
    ④ PHYSICAL 열의 ✎ 클릭 ➔ 창고 실사 수량 입력.
  • 4단계:
    파란색 ADD로 선적 일자 열 추가 ➔ 출하 수량 입력 ➔ SET 옆 체크박스 선택 후 초록색 SET 클릭.
🖥️ Shipment 화면 (Contract-001) PO Qty, ② PACKED, 일자별 ③ SHIPPED 및 ④ PHYSICAL 현황
🖥️ Shipment 화면 (Contract-002) 스타일별 포장 및 선적 수량 비교 예시
12. Stock — 완제품 재고 조회 (/mrp/buyer-order/stock)

📌 용도: Shipment 데이터를 자동 집계하는 조회 전용 완제품 재고 리포트입니다. 날짜(기본 TODAY) 선택 ➔ APPLY 클릭 ➔ 필요 시 D/L LIST로 엑셀 다운로드.

🖥️ Contract Status › Stock 화면 완제품 재고 종합 현황
8단계: 시스템 관리

13. 계정 및 프로필 관리 (ADMIN)

📁 메뉴: ADMIN ▶ Account / Profile / Logout
13. Admin › Account & Profile

• ADMIN ▶ Account (/mrp/admin/account): 관리자가 + Add로 직원 계정을 생성하고 권한을 설정합니다.
• ADMIN ▶ Profile (/mrp/admin/account/edit): 로그인한 사용자가 개인 정보 수정 및 비밀번호 변경을 수행합니다.
• ADMIN ▶ Logout: 안전하게 로그아웃합니다.

14. 주요 유의사항 & 챗봇 AI

1. + Create new BOM (GENERATE NEW BOM) 클릭 시 바이어나 스타일이 보이지 않나요?▼

2. MAKE PO로 발주를 만들었는데 엑셀 입고(Income) 시 오류가 나고 IN BALANCE에 안 뜨나요?▼
