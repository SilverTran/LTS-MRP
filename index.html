STEP 1: INITIAL MASTER DATA SETUP

1. Master Configuration (CONFIG)

📁 Menu: CONFIG ▶ Buyer / Supplier / Consignee / Exchange / Code / Location
1. What Are the 6 Pages in CONFIG Used For?

Before creating BOMs, Contracts, or Purchase Orders, declare your organization's master data across these 6 pages:

✅ WHAT TO ENTER & HOW TO OPERATE EACH CONFIG PAGE:
  • 1. Buyer:
    CONFIG ▶ Buyer (/mrp/config/buyer): Enter customer names (e.g. Buyer-001), address, phone, and PIC. Click green + Add ➔ Save.
  • 2. Supplier:
    CONFIG ▶ Matl. supplier (/mrp/config/matl-supplier): Enter raw material vendors (e.g. Supplier-001). Click + Add ➔ Save.
  • 3. Consignee:
    CONFIG ▶ Matl. consignee (/mrp/config/matl-consignee): Enter receiving legal entity printed on POs (e.g. BETHELVINA CO.,LTD).
  • 4. Exchange:
    CONFIG ▶ Exchange (/mrp/config/exchange): Enter currency exchange rates (USD, VND, KRW, CNY...) and click green APPLY.
  • 5. Code:
    CONFIG ▶ Code (/mrp/config/code): Contains 6 master tables on 1 screen: R/M Category, Unit, MA #, Color code-Item, Color code-Material, and Style code (bottom-right). Click + ADD per table (or ⬇ TEM / ⬆ UP for Excel).
  • 6. Location:
    CONFIG ▶ Location (/mrp/config/location): Enter warehouse & factory locations (e.g. Factory01-Material-T001, Factory01-Material-T002).
🖥️ Full-Screen Config › Code (6 Master Code Tables) Bottom-right Style code table: Click + ADD to register Style codes & names before creating a BOM
💬 Ask Chatbot: Details of the 6 tables in Config › Code
STEP 2: RAW MATERIAL CATALOG

2. Material Master (Raw Materials)

📁 Menu: INVENTORY CONTROL ▶ Material Master
2. Material Master (/mrp/inventory-control/material-master)

Used to register master profiles of every Raw Material before using them in BOMs or Purchase Orders: Supplier, Category (FABRIC, MESH, PACKING), MA #, Name, Color, Unit, Unit Price, Currency, and Spec.

✅ HOW TO CREATE RAW MATERIALS:
  • OPTION 1:
    Create single material on web: Click green + Create ➔ fill Supplier, Category, MA#, Name, Color, Unit, Price, Currency ➔ Save. System auto-generates codes (FAB00000001, MES00000001, PAK00000001).
  • OPTION 2:
    Bulk import via Excel: Click orange Template ➔ fill materials matching Config › Code ➔ click teal Import to upload all at once.
🖥️ Material Master List Screen Example: 5 registered materials (FAB00000001, FAB00000002, MES00000001, MES00000002, PAK00000001)
STEP 3: TECHNICAL BILL OF MATERIALS

3 & 4. BOM List & BOM Manage

📁 Menu: BOM DATA ▶ List / Manage
3. BOM List (/mrp/bom-data/list)

Used to initialize a new BOM (select Buyer, Style code, Revision like v0.1), clone an existing BOM (COPY) to another style, or LOCK / UNLOCK editing.

✅ STEP-BY-STEP OPERATIONS:
  • STEP 1:
    Create New or Copy: Click green + Create new BOM ➔ in GENERATE NEW BOM, select BUYER (Buyer-001), STYLE CODE (Stl001), enter REVISION (v0.1) ➔ click GENERATE.
    ⚠️ If Buyer or Style is missing in the dropdown, add it first in CONFIG › Code (Style code table) or CONFIG › Buyer!
  • STEP 2:
    Click green MANAGE on the BOM row to enter material details in Bom › Manage.
  • STEP 3:
    Once finished, return to Bom › List, tick the row checkbox, and click red LOCK to prevent accidental edits (click UNLOCK to reopen).
🖥️ BOM Data › List Screen Shows registered BOMs (Stl001, Stl002) with MANAGE and COPY action buttons
🖥️ GENERATE NEW BOM Modal (+ Create new BOM) Select BUYER, STYLE CODE, and REVISION then click GENERATE
4. BOM Manage (/mrp/bom-data/manage)

Used to enter material lines and net consumption per 1 finished unit: product colors (Color option), material groups (Group#1), raw material codes (SEL), color assignment (specific color or COMMON), and cut pieces (L × W).

✅ STEP-BY-STEP OPERATIONS:
  • STEP 1:
    Click blue Basic info ➔ verify Mode is Manage ➔ add garment colors in Color option (Black-001, White-001).
  • STEP 2:
    Click Add GP on the first column header to create Group#1, then click + to add material rows.
  • STEP 3:
    In COLOR CODE: Checked (☑) = COLOR mode (splits per colorway like Black-001, White-001); Unchecked (☐) = COMMON mode (single row shared across all colors). Then click blue SEL in R/M CODE to pick from Material Master.
  • STEP 4:
    On the right panel, add cut pieces (Part-1 > Piece-1) and enter L × W. System auto-saves immediately.
🖥️ BOM Manage — Basic info Modal Configure Mode (Manage), Color options, and PIC
🖥️ BOM Manage — Left Panel (Groups, Color Code & R/M Code) Example Stl001: Group#1 with Fabrics, Mesh, and Packing assigned by color/COMMON
🖥️ BOM Manage — Right Panel (Cut Parts L × W & Total Consumption) Auto-calculated consumption per unit
STEP 4: CUSTOMER CONTRACT & ORDER

5. Contract Management (Contract Status › Active)

📁 Menu: CONTRACT STATUS ▶ Active
5. Contract › Active (/mrp/contract-status/active)

Used to enter customer Contracts: Contract #, Buyer, child PO #, PO/Ship dates, Style code, Color/Size PO Qty, Labor cost, FOB price, and link the matching BOM.

✅ 5 STEPS TO CREATE A CONTRACT:
  • STEP 1:
    Click green + Add CONTRACT (or click ✎ Contract-001 to edit) to open MANAGE ORDER.
  • STEP 2:
    Enter Contract # (Contract-001), select Buyer (Buyer-001), and click + Add PO.
  • STEP 3:
    Enter PO # (PO 1), PO date, Target ship date, then click + Add Style.
  • STEP 4:
    Select Style code (Stl001), enter Season, Labor cost, FOB, click + to add colors (Black-001, White-001) and PO Qty.
  • STEP 5:
    Ensure the BOM button shows green (Match), then scroll down and click SAVE.
🖥️ Contract Status › Active List Example: Contract-001 & Contract-002 with green Match BOM status
🖥️ MANAGE ORDER Modal (+ Add CONTRACT) Full contract, PO, Style, Color/Qty, and BOM match configuration
STEP 5: MRP CALCULATION & PURCHASING

6 & 7. Purchase Order (MRP) & Mat PO status

📁 Menu: INVENTORY CONTROL ▶ Purchase Order / Mat PO status
6. Purchase Order (/mrp/inventory-control/purchase-order)

Used to calculate raw material demand and issue Material POs (PO-R-...): enter ② LOSS %, ② ASSIGN, ① ORDER QTY, ③ UNIT PRICE, CONSIGNEE, RM PO DATE / RM ETA, and switch Status from STANDBY to ORDERED.

✅ 5 STEPS TO ISSUE A VALID MATERIAL PO:
  • STEP 1:
    Select Contract: Choose CONT # (Contract-001). If CONS.(BOM)(AFTER) shows red numbers (14400, 2400, 300), tick the checkbox and click green UPDATE.
  • STEP 2:
    Enter Loss %: Click values in ② LOSS % (or tick & click SET) to add production wastage %.
  • STEP 3:
    Click MAKE PO (or ADD): Tick rows of the same Supplier in the SUPPLIER column ➔ click MAKE PO to generate PO-R-YYMMDD-XXX.
  • STEP 4:
    Verify Order Qty, Price & Dates: Scroll right to Ⓔ MATERIAL PURCHASE ORDER to check/edit ORDER QTY, UNIT PRICE, CONSIGNEE, RM PO DATE, RM ETA.
  • STEP 5:
    ⚠️ MANDATORY — Switch STANDBY ➔ ORDERED: Scroll to the rightmost STATUS column, click STANDBY (or green INFO), switch to ORDERED and click APPLY. Only ORDERED POs can be received in Income status!
🖥️ Purchase Order (Contract-001) - Part 1: Material Info, BOM Consumption & Global PO Qty Shows MATERIAL INFORMATION, Ⓑ BOM CONSUMPTION (red numbers 14400, 2400, 300 in CONS.(BOM)(AFTER)) and Ⓒ GLOBAL PO QTY
🖥️ Purchase Order (Contract-001) - Part 2: Ⓔ MATERIAL PURCHASE ORDER & Ⓕ DELIVERY Shows order quantities (7200, 1200, 1000, 200), unit prices (1, 1.5), AMOUNT (18000 & 2400 USD), PO date (2026/11/16) and STATUS (MATERIAL)
🖥️ Purchase Order (Contract-002) - Before Creating PO (Pre-MAKE PO) Rows show ADD buttons and SUPPLIER checkboxes ready to tick by Supplier and click MAKE PO
7. Mat PO status — View-Only PO Tracking (/mrp/inventory-control/mat-po-status)

📌 Purpose: View-only tracking of all issued Material POs (STATUS, AMOUNT, ① ORDER, ② W/H IN, ①-② BALANCE). Click Manage PO Group to jump back to Purchase Order if edits are needed.

🖥️ Mat PO status Screen Shows PO-R-261116-001 ($18,000) & PO-R-261116-002 ($2,400) in ORDERED status
STEP 6: WAREHOUSE RECEIVING, ISSUING & STOCK

8, 9 & 10. Income status, Outgo status & Inventory

📁 Menu: INVENTORY CONTROL ▶ Income / Outgo / Inventory
8. Income status — Warehouse Receiving (/mrp/inventory-control/income-status)

Used to upload Excel receiving slips when Suppliers deliver materials (fill from Row 3: DATE-NO YYYY/MM/DD-SN, SUPPLIER, LOCATION, CONTRACT #, CODE, QTY, UNIT, PRICE, AMOUNT, CURRENCY, BUYER, DEBIT, MA #, INSPECTION YYYY.MM.DD).

✅ 4 STEPS TO RECEIVE MATERIALS:
  • STEP 1:
    Verify the PO is in ORDERED status in Purchase Order.
  • STEP 2:
    Click orange TEMPLATE to download the official Excel template and fill items starting from Row 3.
  • STEP 3:
    Click blue UPLOAD EXCEL and select your file. System auto-matches MATL PO #.
  • STEP 4:
    Confirm • ERROR: 0 (yellow WARNING like [WPO] is non-blocking) ➔ click green ✔ APPLY INCOME ➔ YES.
🖥️ Income status After Excel Upload (5 Rows for Contract-001) Live example: • ERROR: 0 • WARNING: 1 ([WPO]Buyer-002 on row 4), auto-matched MATL PO # — ready to click ✔ APPLY INCOME
9. Outgo status — Warehouse Issuing (/mrp/inventory-control/outgo-status)

Used to upload Excel issue slips when issuing materials from warehouse to production (fill from Row 3; note DATE-NO uses 2-digit year YY/MM/DD-SN, plus FROM and TO locations).

✅ 3 STEPS TO ISSUE MATERIALS:
  • STEP 1:
    Click orange TEMPLATE to download the official Outgo template and fill rows starting at Row 3.
  • STEP 2:
    Click blue UPLOAD EXCEL and upload the file.
  • STEP 3:
    Confirm • ERROR: 0 ➔ click green ✔ APPLY OUTGO ➔ YES.
🖥️ Outgo status After Excel Upload (5 Rows for Contract-001) Live example: • ERROR: 0 • WARNING: 2 ([WPO]), issuing 2000 YDS fabric, 400 & 300 MET mesh, 100 PCS packing — ready to click ✔ APPLY OUTGO
10. Inventory — View Raw Material Stock (/mrp/inventory-control/inventory)

📌 Purpose: Real-time stock inquiry (IN, IN BALANCE, OUT, INVENTORY). Default filter is NOT ZERO (switch to SHOW ALL + 🔍 Refresh to see zero-stock items). Click HISTORY for transaction ledger or D/L XLS by BUYER / MA# to export.

🖥️ Inventory Screen After Receiving & Issuing (NOT ZERO Filter) Live example (Contract-001): IN (5000, 5000, 1000, 800, 200), IN BALANCE (2200, 2200, 200, 200, 0), and OUT (4200, 4200, 600, 500, 100)
STEP 7: PACKING, SHIPPING & FINISHED GOODS STOCK

11 & 12. Shipment & Finished Goods Stock

📁 Menu: CONTRACT STATUS ▶ Shipment & Stock
11. Shipment (/mrp/buyer-order/shipment)

Used strictly for Finished Goods packing & shipping: enter ② PACKED, ④ PHYSICAL count, and daily ③ SHIPPED quantities.

✅ 4 STEPS TO RECORD PACKING & SHIPPING:
  • STEP 1:
    Select BUYER and CONTRACT #, then click green APPLY.
  • STEP 2:
    Click ✎ under ② PACKED ➔ pick date, enter packed qty, and save.
  • STEP 3:
    Click ✎ under ④ PHYSICAL ➔ enter physical warehouse count.
  • STEP 4:
    Click blue ADD to add a shipment date column ➔ enter shipped qty ➔ tick the checkbox next to SET and click green SET.
🖥️ Shipment Screen (Contract-001) Shows PO Qty, ② PACKED, ③ SHIPPED by date, and ④ PHYSICAL columns
🖥️ Shipment Screen (Contract-002) Example comparing packed and shipped quantities across styles
12. Stock — View Finished Goods Stock (/mrp/buyer-order/stock)

📌 Purpose: View-only summary report of Finished Goods stock (auto-aggregated from Shipment). Select date (default TODAY) ➔ click APPLY ➔ click D/L LIST to export Excel.

🖥️ Contract Status › Stock Screen Summary Finished Goods stock report

QUICK TROUBLESHOOTING

14. Key Operational Notes & Chatbot AI

1. Buyer or Style Code is missing when clicking + Create new BOM (GENERATE NEW BOM)?▼
Go to CONFIG › Code (bottom-right Style code table) and click + ADD to add the Style, or go to CONFIG › Buyer and click + Add to add the Buyer first.
2. Created a PO with MAKE PO, why does Excel Income upload fail or Inventory show no IN BALANCE?▼
Newly created POs default to STANDBY. Scroll to the rightmost STATUS column on Purchase Order and switch it to ORDERED.
3. Need deeper lookup (Column meanings, Excel EFM/ECD/ECT error codes, 7 common mistakes)?▼
Open the Chatbot AI 💬 at the bottom-right corner — you can ask in English, Vietnamese, or Korean!
