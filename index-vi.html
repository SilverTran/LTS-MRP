1. Trang Thiết Lập Danh Mục Gốc & 6 Bảng Mã Chuẩn (Config)

📁 Menu: CONFIG ▶ Buyer / Supplier / Consignee / Exchange / Code / Location
1. Các Trang Thiết Lập Danh Mục Chuẩn (Phân Hệ CONFIG)
📝 Các trang trong menu CONFIG dùng để nhập cái gì?

Dùng để nhập toàn bộ dữ liệu danh mục nền tảng trước khi tạo Hợp đồng, BOM hay Đơn mua PO:
1. Config › Buyer (/mrp/config/buyer): Nhập tên Khách hàng (Buyer-001, Buyer-002), địa chỉ, SĐT và người liên hệ (PIC).
2. Config › Matl. supplier (/mrp/config/matl-supplier): Nhập thông tin Nhà cung cấp nguyên phụ liệu (Supplier-001, Supplier-002), quốc gia, SĐT và người liên hệ.
3. Config › Matl. consignee (/mrp/config/matl-consignee): Nhập tên Pháp nhân / Nhà máy nhận hàng in trên đơn PO (BETHELVINA CO.,LTD).
4. Config › Exchange (/mrp/config/exchange): Nhập tỷ giá quy đổi giữa các đồng tiền (USD, VND, KRW, CNY, JPY, EUR).
5. Config › Code (/mrp/config/code): Nhập 6 bảng mã chuẩn trên cùng 1 màn hình gồm: Nhóm vật tư (R/M Category: FABRIC, MESH, PACKING), Đơn vị tính (Unit: YDS, MET, PCS), Mã quản lý (MA #), Mã màu sản phẩm (Color code-Item), Mã màu nguyên phụ liệu (Color code-Material) và Mã kiểu dáng (Style code: Stl001, Stl002).
6. Config › Location (/mrp/config/location): Nhập mã các Vị trí kho và Xưởng sản xuất (Factory01-Material-T001, Factory01-Material-T002...).

✅ CÁC BƯỚC THAO TÁC ĐỂ NHẬP DỮ LIỆU TRONG PHÂN HỆ CONFIG:
  • BƯỚC 1:
    Tại các trang Buyer, Matl. supplier, Matl. consignee, Location:
    Bấm nút xanh lá + Add ở góc trái ➔ điền Tên, Địa chỉ, SĐT và thông tin người liên hệ (PIC) ➔ bấm Save. (Nếu muốn sửa dòng đã có, bấm nút Manage hoặc Edit ở dòng đó).
  • BƯỚC 2:
    Tại trang Config › Code (6 Bảng mã chuẩn):
    • Thêm lẻ từng mã: Tại khung bảng mã tương ứng (VD: Style code hoặc Color code-Item), bấm nút xanh lá + ADD ➔ nhập Mã và Tên ➔ bấm lưu.
    • Thêm hàng loạt bằng Excel: Bấm nút vàng cam ⬇ TEM để tải mẫu Excel của bảng đó ➔ điền danh sách mã ➔ bấm nút xanh dương ⬆ UP để tải lên.
  • BƯỚC 3:
    Tại trang Config › Exchange (Tỷ giá ngoại tệ):
    Nhập trực tiếp tỷ giá quy đổi mới vào ô tương ứng rồi bấm nút xanh lá APPLY để cập nhật.
🖥️ Giao diện trang Config › Code (Nhập 6 bảng mã chuẩn trên cùng 1 màn hình) Mỗi bảng đều có nút + ADD (thêm lẻ), ⬆ UP (tải Excel) và ⬇ TEM (tải file mẫu)

2. Trang Danh Mục Nguyên Phụ Liệu Gốc (Material Master)

📁 Đường dẫn Menu: INVENTORY CONTROL ▶ Material Master (/mrp/inventory-control/material-master)

📝 Trang này dùng để nhập cái gì?

Dùng để khai báo hồ sơ gốc của từng loại nguyên phụ liệu trước khi đưa vào BOM hoặc mua hàng, gồm: Nhà cung cấp (Supplier), Nhóm vật tư (Category: Vải, Lưới, Bao bì), Mã nhóm quản lý (MA #), Tên tiếng Việt (NPL Name), Tên tiếng Anh (R/M Name), Màu vật tư (Color), Đơn vị tính (Unit), Đơn giá mua (Unit Price), Tiền tệ (Currency) và Quy cách (Spec).

✅ CÁC BƯỚC THAO TÁC ĐỂ THÊM MỚI NGUYÊN PHỤ LIỆU:
  • CÁCH 1:
    Nhập từng mã nguyên phụ liệu trực tiếp trên web:
    1. Bấm nút xanh lá + Create ở góc trên bên trái.
    2. Chọn Supplier (VD: Supplier-001), Category (FABRIC / MESH / PACKING), MA # (MA001), nhập Tên vật tư (Fabric name 001), chọn Màu (Blue-321), ĐVT (YDS / MET / PCS) và nhập Đơn giá ($1.0000 USD).
    3. Bấm lưu để hệ thống tự động cấp mã chuẩn (VD trên ảnh: 8 mã FAB00000001..004, MES00000001..002, PAK00000001..002).
  • CÁCH 2:
    Nhập hàng loạt từ file Excel hoặc Google Sheets:
    1. Bấm nút vàng cam Template để tải file Excel mẫu về máy.
    2. Điền danh sách nguyên phụ liệu vào file mẫu theo đúng các mã đã có trong Config › Code.
    3. Bấm nút xanh ngọc Import (hoặc Import (From Sheets)) và chọn file vừa điền để nạp toàn bộ danh sách lên hệ thống.
🖥️ Giao diện toàn màn hình trang Inventory control › Material Master Ví dụ 8 mã nguyên phụ liệu gốc (FAB00000001..004, MES00000001..002, PAK00000001..002) hiển thị đầy đủ các cột

3 & 4. Trang Quản Lý Định Mức Kỹ Thuật (Bom › List & Manage)

3. Trang Danh Sách Định Mức (Bom › List)
📝 Trang này dùng để nhập cái gì?

Dùng để khởi tạo tên bảng định mức BOM mới (chọn BUYER, chọn mã hàng STYLE CODE, đặt tên phiên bản REVISION như v0.1), hoặc nhân bản nhanh (COPY) một bảng BOM đã có sang mã hàng mới, và Khóa / Mở khóa (LOCK / UNLOCK) quyền chỉnh sửa BOM.

✅ CÁC BƯỚC THAO TÁC TRÊN TRANG BOM › LIST:
  • BƯỚC 1:
    Tạo BOM mới (+ Create new BOM) hoặc Sao chép BOM (COPY):
    • Khi tạo mới: Bấm nút xanh lá + Create new BOM ở góc trái để mở hộp thoại GENERATE NEW BOM ➔ Chọn khách hàng tại ô BUYER (VD: Buyer-001), chọn mã hàng tại ô STYLE CODE (VD: Stl001 - tên STYLE NAME sẽ tự động điền), nhập phiên bản vào ô REVISION (VD: v0.1) rồi bấm nút xanh lá GENERATE.
    • ⚠️ Lưu ý quan trọng: Nếu trong cửa sổ GENERATE NEW BOM bạn không tìm thấy tên Khách hàng (BUYER) hoặc không thấy tên Mã hàng (STYLE CODE) trong danh sách xổ xuống, hãy vào menu CONFIG ▶ Code (tại bảng Style code góc dưới bên phải để bấm + ADD tạo thêm mã Style mới) hoặc vào CONFIG ▶ Buyer (để tạo thêm Khách hàng mới) trước!
    • Khi sao chép từ BOM tương tự: Bấm nút xanh dương COPY ở cuối dòng BOM mẫu (VD: copy từ Stl001 v0.1 sang Stl002 v0.1) để tiết kiệm thời gian nhập lại.
  • BƯỚC 2:
    Bấm nút màu xanh lá MANAGE ở cuối dòng BOM vừa tạo để chuyển sang trang Bom › Manage và bắt đầu nhập chi tiết nguyên phụ liệu.
  • BƯỚC 3:
    Sau khi đã hoàn thiện định mức và muốn chống sửa nhầm, quay lại trang Bom › List, tick chọn ô vuông ở dòng BOM đó rồi bấm nút đỏ LOCK trên tiêu đề cột (bấm UNLOCK khi cần mở lại để sửa).
🖥️ Giao diện toàn màn hình trang Bom › List Danh sách các bảng định mức Stl001 (v0.1, v0.2) và Stl002 (v0.1)
🖥️ Hộp thoại GENERATE NEW BOM khi bấm nút + Create new BOM Nếu không thấy tên Khách hàng (BUYER) hoặc Mã hàng (STYLE CODE), cần vào trang CONFIG › Buyer hoặc CONFIG › Code để tạo thêm
4. Trang Nhập Chi Tiết Định Mức Kỹ Thuật (Bom › Manage)
📝 Trang này dùng để nhập cái gì?

Dùng để nhập cấu trúc nguyên phụ liệu để sản xuất ra 1 sản phẩm hoàn chỉnh, bao gồm: các màu của sản phẩm (Color option), các nhóm vật tư (Group#1, Group#2...), chọn mã nguyên phụ liệu từ danh mục gốc (R/M Code), chỉ định vật tư đó dùng cho màu nào (Black-001, White-001 hay dùng chung COMMON), và nhập tên chi tiết cắt (PART > PIECE NAME) cùng kích thước Dài (L) × Rộng (W) × Số mảnh (PCS) để hệ thống tự tính ra lượng tiêu hao (CONSUMPTION) và đơn giá vật tư cho 1 sản phẩm.

✅ CÁC BƯỚC THAO TÁC ĐỂ HOÀN THÀNH BẢNG ĐỊNH MỨC TRÊN BOM › MANAGE:
  • BƯỚC 1:
    Nếu vào trực tiếp từ menu BOM DATA ▶ Manage, bấm nút xanh lá Open BOM ở góc trái để chọn bảng BOM cần làm việc (VD: Buyer-001 | Stl001 | v0.1). Tiếp theo bấm nút xanh dương Basic info: Đảm bảo trạng thái là Manage và thêm đủ các màu của sản phẩm tại mục Color option ➔ Add (VD: Black-001, White-001).
  • BƯỚC 2:
    Bấm nút Add GP ở cột GROUP để tạo nhóm vật tư (Group#1), sau đó bấm nút dấu cộng + trong nhóm để thêm các dòng nguyên phụ liệu.
  • BƯỚC 3:
    Tại mỗi dòng nguyên phụ liệu (khối RAW MATERIAL bên trái):
    • Ở cột COLOR CODE: Tick chọn (☑) = chế độ COLOR (tách riêng từng màu sản phẩm như Black-001, White-001 để chọn mã vật tư khác nhau cho mỗi màu); Bỏ tick (☐) = chế độ COMMON (1 dòng dùng chung vật tư cho tất cả các màu).
    • Ở cột R/M CODE: Bấm nút xanh dương SEL ➔ chọn mã nguyên phụ liệu từ Material Master.
    👉 Ví dụ trực quan trên ảnh (Stl001 v0.1): Dòng 1 (tick ☑ COLOR) chọn vải FAB00000001 cho màu Black-001 và FAB00000002 cho màu White-001; Dòng 2 & 3 (tick ☑) chọn lưới MES00000001 & MES00000002; Dòng 4 (bỏ tick ☐ COMMON) chọn túi đóng gói PAK00000001 dùng chung mọi màu.
  • BƯỚC 4:
    Tại khối CATEGORY & CONSUMPTION bên phải: Bấm nút xanh dương MANAGE để nhập các chi tiết cắt (VD: Part-1 > Piece-01, Piece-02... với chiều dài L, chiều rộng W, số chi tiết PCS). Hệ thống lập tức tự tính ra cột CONSUMPTION (VD: 7.2 YDS vải, 1.2 MET lưới, 0.1 PCS bao bì) và tổng giá vốn vật tư MATERIAL COST (MAIN COLOR) = $8.5000!
🖥️ Giao diện trang Bom › Manage - Phần Trái (Khối RAW MATERIAL & Chi tiết cắt) Ví dụ Stl001 v0.1: Chọn mã vải/lưới/bao bì theo từng màu Black-001, White-001 hoặc COMMON
🖥️ Giao diện trang Bom › Manage - Phần Phải (Khối CATEGORY, CONSUMPTION & MATERIAL COST) Tự động tính định mức tiêu hao (7.2 YDS, 1.2 MET, 0.1 PCS) và tổng giá vốn vật tư $8.5000

BƯỚC 4: TẠO HỢP ĐỒNG

5. Trang Quản Lý Hợp Đồng (Contract Status › Active)

📁 Menu: CONTRACT STATUS ▶ Active (/mrp/contract-status/active)
📝 Trang này dùng để nhập cái gì?

Dùng để nhập Hợp đồng mới của khách hàng, bao gồm: Mã hợp đồng (Contract #), Khách hàng (Buyer), các đơn hàng con (PO #, Ngày PO, Ngày giao hàng), Mã kiểu dáng (Style code), Số lượng đặt hàng theo từng Màu/Size (PO Qty), Giá gia công (Labor cost), Giá bán (FOB) và chọn phiên bản định mức (BOM) áp dụng cho mã hàng đó.

✅ CÁC BƯỚC THAO TÁC ĐỂ HOÀN THÀNH MỤC TIÊU TẠO & KHỚP HỢP ĐỒNG:
  • BƯỚC 1:
    Tại góc trên bên trái màn hình Contract Status › Active, bấm nút màu xanh lá + Add CONTRACT (hoặc nhấp vào mã ✎ Contract-001 trên bảng nếu muốn sửa hợp đồng đã có) để mở cửa sổ MANAGE ORDER.
  • BƯỚC 2:
    Ở hàng trên cùng của cửa sổ MANAGE ORDER: Nhập mã hợp đồng vào ô Contract # (VD: Contract-001), chọn khách hàng tại ô Buyer (VD: Buyer-001), sau đó bấm nút + Add PO để thêm đơn đặt hàng.
  • BƯỚC 3:
    Nhập số PO # (VD: PO 1), chọn ngày PO date (VD: 2026/11/01), ngày xuất dự kiến Requested / Target ship date, rồi bấm nút + Add Style ở góc phải khung PO.
  • BƯỚC 4:
    Chọn mã hàng tại ô Style code (VD: chọn Stl001 và thêm tiếp tab Stl002). Bấm nút ADD ở bảng màu bên dưới để chọn các màu và nhập số lượng + đơn giá.
    👉 Ví dụ trực quan trên ảnh: Hợp đồng Contract-001 (PO 1) nhập mã Stl001 gồm màu Black-001 (Số lượng Qty = 1000, Đơn giá Unit price = 16 ➔ Thành tiền $16,000) và màu White-001 (Qty = 1000, Unit price = 16 ➔ $16,000).
  • BƯỚC 5:
    Kiểm tra cột BOM ở cuối mỗi dòng màu: nếu đã hiện chữ xanh lá Match nghĩa là mã hàng và màu đó đã khớp định mức kỹ thuật (bấm nút Material Cost nếu muốn xem tổng giá vốn nguyên phụ liệu). Cuối cùng kéo xuống dưới cùng bấm nút SAVE để lưu hợp đồng.
    • Lưu ý tránh lỗi thao tác: Nếu bấm + Add CONTRACT nhưng đổi ý đóng cửa sổ ngay mà chưa nhập gì, hệ thống sẽ tạo ra 1 dòng trống (___) trên bảng Active — khi đó hãy tick ô vuông cột DEL của dòng trống đó và bấm nút đỏ DEL để xóa.
🖥️ Giao diện toàn màn hình trang Contract Status › Active (Click vào ảnh để phóng to) Ví dụ thực tế: Contract-001 (3,000 sp) & Contract-002 (4,000 sp) hiển thị đầy đủ các cột từ trái sang phải
🖥️ Giao diện toàn màn hình cửa sổ MANAGE ORDER của Contract-001 Ví dụ: PO 1 gồm Stl001 (Black-001: 1,000 sp & White-001: 1,000 sp) và Stl002 đều báo BOM = Match (Xanh lá)

6 & 7. Trang Đặt Mua MRP (Purchase Order) & Xem Tiến Độ PO (Mat PO status)

6. Trang Tính Toán Nhu Cầu & Phát Hành Đơn Mua Vật Tư (Purchase Order - Trọng Tâm MRP)

📁 Đường dẫn Menu: INVENTORY CONTROL ▶ Purchase Order (/mrp/inventory-control/purchase-order)

📝 Trang này dùng để nhập cái gì?

Dùng để lập và phát hành Đơn đặt mua nguyên phụ liệu (MATERIAL PO #) gửi Nhà cung cấp cho từng Hợp đồng. Tại đây bạn nhập: Tỷ lệ hao hụt sản xuất (② LOSS %), Số lượng lấy từ tồn kho có sẵn (② ASSIGN), Số lượng đặt mua thực tế (① ORDER QTY), Đơn giá mua (③ UNIT PRICE), Đơn vị nhận hàng (CONSIGNEE), Ngày đặt hàng / Ngày dự kiến hàng về (RM PO DATE / RM ETA), và chuyển trạng thái đơn mua từ STANDBY sang ORDERED.

✅ 5 BƯỚC THAO TÁC ĐỂ HOÀN THÀNH PHÁT HÀNH ĐƠN MUA (PO) HỢP LỆ:
  • BƯỚC 1:
    Chọn Hợp đồng cần mua vật tư:
    Tại ô CONT # trên đầu trang, chọn mã Hợp đồng (VD: Contract-001 hoặc Contract-002). Hệ thống lập tức liệt kê toàn bộ nguyên phụ liệu của hợp đồng đó. (Lưu ý: Nếu con số ở cột CONS.(BOM)(AFTER) hiện màu đỏ như 14400, 2400, 300 trên ảnh, nghĩa là định mức BOM vừa cập nhật khác với cột BEFORE — bạn có thể tick chọn ô vuông đầu cột và bấm nút xanh lá UPDATE nếu muốn lấy theo định mức mới).
  • BƯỚC 2:
    Nhập tỷ lệ hao hụt (② LOSS %) nếu có:
    Nhấp vào con số ở cột ② LOSS % (hoặc tick nhiều dòng rồi bấm nút SET trên tiêu đề cột) để nhập % hao hụt bù trừ sản xuất ➔ hệ thống tự động cộng thêm vào tổng nhu cầu ③ CONS.(LOSS).
  • BƯỚC 3:
    Bấm MAKE PO để tạo mã đơn mua (hoặc bấm ADD để gộp vào PO đã có):
    • Tick chọn các ô vuông tại cột SUPPLIER của các dòng vật tư thuộc cùng một Nhà cung cấp ➔ bấm nút xanh lá MAKE PO trên tiêu đề cột.
    👉 Ví dụ trực quan trên ảnh (Contract-001): Tick 2 dòng vải (FAB00000001: 7,200 YDS & FAB00000002: 7,200 YDS) của Supplier-001 ➔ bấm MAKE PO sinh ra đơn PO-R-261116-001 (Tổng tiền AMOUNT = $18,000 USD). Tiếp tục tick 3 dòng lưới & bao bì của Supplier-002 ➔ bấm MAKE PO sinh ra đơn PO-R-261116-002 (AMOUNT = $2,400 USD).
  • BƯỚC 4:
    Kiểm tra / Nhập Số lượng đặt mua, Đơn giá & Thông tin giao nhận:
    Tại khối Ⓔ MATERIAL PURCHASE ORDER bên phải: Nhấp trực tiếp vào các ô ① ORDER QTY (Số lượng đặt), ② ASSIGN (Số lượng lấy từ kho nếu có), ③ UNIT PRICE (Đơn giá: 1, 1.5), CONSIGNEE, RM PO DATE (2026/11/16) và RM ETA để kiểm tra hoặc chỉnh sửa rồi bấm APPLY.
  • BƯỚC 5:
    ⚠️ BẮT BUỘC: Chuyển trạng thái PO từ STANDBY sang ORDERED:
    Cuộn ngang bảng sang tận cùng bên phải tới cột STATUS (ngay sau cột STATUS (MATERIAL) ở cuối ảnh 2): Khi mới bấm MAKE PO, trạng thái mặc định là STANDBY (chờ duyệt). Bạn phải nhấp vào chữ STANDBY (hoặc bấm nút xanh lá INFO dưới cột STATUS (MATERIAL)), chọn đổi sang ORDERED rồi bấm APPLY.
    👉 Chỉ khi đã chuyển sang ORDERED thì số lượng đặt mua mới hiện lên ở cột IN BALANCE trong Kho và trang Income status mới cho phép bạn nhập kho lô hàng này!
🖥️ Giao diện trang Purchase Order (Contract-001) - Phần 1: Thông tin vật tư, Định mức BOM & Tổng nhu cầu Hiển thị khối MATERIAL INFORMATION, Ⓑ BOM CONSUMPTION (chữ đỏ 14400, 2400, 300 ở cột CONS.(BOM)(AFTER)) và Ⓒ GLOBAL PO QTY
🖥️ Giao diện trang Purchase Order (Contract-001) - Phần 2: Khối Ⓔ MATERIAL PURCHASE ORDER & Ⓕ DELIVERY Hiển thị số lượng đặt mua (7200, 1200, 1000, 200), đơn giá (1, 1.5), tổng tiền AMOUNT (18000 & 2400 USD), ngày đặt (2026/11/16) và cột STATUS (MATERIAL)
🖥️ Giao diện trang Purchase Order (Contract-002) - Trạng thái chưa tạo đơn mua (chưa bấm MAKE PO) Các dòng vật tư hiện nút ADD và ô tick ở cột SUPPLIER (chưa gộp PO) — sẵn sàng tick chọn theo Supplier để bấm MAKE PO

8. Trang Nhập Kho Nguyên Phụ Liệu (Income status)

📁 Đường dẫn Menu: INVENTORY CONTROL ▶ Income status (/mrp/inventory-control/income-status)

📝 Trang này dùng để nhập cái gì?

Dùng để tải file Excel phiếu nhập kho khi Nhà cung cấp giao nguyên phụ liệu về kho. Nội dung nhập trên file Excel (bắt đầu từ dòng thứ 3) gồm: Ngày-Số phiếu (DATE-NO định dạng YYYY/MM/DD-SN), Nhà cung cấp (SUPPLIER), Vị trí kho nhận (LOCATION), Mã Hợp đồng (CONTRACT #), Mã nguyên phụ liệu (CODE), Tên vật tư (NAME), Số lượng thực nhập (QTY), Đơn vị tính (UNIT), Đơn giá (PRICE), Thành tiền (AMOUNT), Tiền tệ (CURRENCY), Khách hàng (BUYER), Khấu trừ (DEBIT), Mã MA # và Ngày kiểm tra chất lượng (INSPECTION định dạng YYYY.MM.DD).

✅ 4 BƯỚC THAO TÁC ĐỂ HOÀN THÀNH NHẬP KHO NGUYÊN PHỤ LIỆU:
  • BƯỚC 1:
    Kiểm tra điều kiện trước khi nhập kho:
    Đảm bảo đơn mua của lô hàng đó đã được chuyển từ STANDBY sang ORDERED tại trang Purchase Order (nếu chưa đổi sang ORDERED, khi tải file Excel sẽ báo lỗi không nhận diện được PO).
  • BƯỚC 2:
    Chuẩn bị file Excel nhập kho (Từ dòng thứ 3 trở đi):
    Bấm nút vàng cam TEMPLATE trên màn hình để tải file Excel mẫu chuẩn của hệ thống về máy và điền dữ liệu từ dòng thứ 3 trở đi.
    👉 Ví dụ 1 dòng nhập kho chuẩn trong file Excel:
    DATE-NO: 2026/11/16-01 | SUPPLIER: Supplier-001 | LOCATION: Factory01-Material-T001 | CONTRACT #: Contract-001 | CODE: FAB00000001 | NAME: Fabric name 001 | QTY: 5000 | UNIT: YDS | PRICE: 1 | AMOUNT: 5000 | CURRENCY: USD | BUYER: Buyer-001 | DEBIT: N | MA #: MA001 | INSPECTION: 2026.11.16.
  • BƯỚC 3:
    Tải file Excel lên bảng kiểm duyệt:
    Bấm nút xanh dương UPLOAD EXCEL trên thanh công cụ và chọn file Excel vừa chuẩn bị. Hệ thống sẽ đọc dữ liệu, tự động khớp cột MATL PO # và kiểm tra lỗi trên từng dòng.
  • BƯỚC 4:
    Kiểm tra báo lỗi và bấm ✔ APPLY INCOME để chốt nhập kho:
    • Quan sát dòng trạng thái phía trên bảng: Khi hiện • ERROR: 0 (không có lỗi đỏ, có thể có WARNING vàng như dòng [WPO]Buyer-002 / Buyer-001 trên ảnh để nhắc kiểm tra lại), bấm nút xanh lá ✔ APPLY INCOME ➔ Chọn YES ở hộp thoại xác nhận để chính thức cộng hàng vào kho.
    • Nếu có báo lỗi đỏ (EFM, ECD, ECT), bấm nút xanh lá INFO để đối chiếu nguyên nhân, sửa lại trên file Excel rồi thực hiện lại Bước 3.
🖥️ Giao diện trang Income status sau khi Upload Excel thành công (5 dòng vật tư của Contract-001) Ví dụ thực tế: Bộ đếm • ERROR: 0 • WARNING: 1 (cảnh báo [WPO]Buyer-002 ở dòng 4), tự động khớp MATL PO # (PO-R-261116-001 & 002) — sẵn sàng bấm ✔ APPLY INCOME

    Kiểm tra bộ đếm báo • ERROR: 0 ➔ bấm nút xanh lá ✔ APPLY OUTGO ➔ Chọn YES để hoàn tất xuất kho chính thức.

✅ CÁC BƯỚC THAO TÁC GIAO HÀNG TRÊN TRANG SHIPMENT:
  • BƯỚC 1:
    Chọn khách hàng tại ô BUYER (VD: Buyer-001) và chọn hợp đồng tại ô CONTRACT # (VD: Contract-001), sau đó bấm nút xanh lá APPLY để tải danh sách mã hàng lên bảng.
  • BƯỚC 2:
    Nhập số lượng Đóng gói (② PACKED): Nhấp vào số có biểu tượng cây bút ✎ ở cột ② PACKED (VD trên ảnh: Stl001 - Black-001 nhập ✎ 500, White-001 nhập ✎ 600, Stl002 - Black-001 nhập ✎ 400).

    Nhập số lượng Kiểm kê (④ PHYSICAL): Nhấp vào biểu tượng cây bút ✎ ở cột ④ PHYSICAL để nhập số lượng kiểm kê thực tế tại kho thành phẩm (VD: ✎ 300, ✎ 100, ✎ 50).
  • BƯỚC 4:
    Nhập lịch và số lượng Xuất giao khách (③ SHIPPED): Bấm nút xanh dương ADD ở góc phải tiêu đề QUANTITY để thêm cột ngày xuất (VD: 2026/11/13) ➔ Nhấp vào ô dưới ngày xuất để gõ số lượng giao (VD: 200, 400, 150) ➔ Tick chọn ô vuông cạnh chữ SET và bấm nút xanh lá SET để lưu.
    👉 Ví dụ kết quả tự tính trên dòng 1 (Stl001 - Black-001): Đặt 1,000 | Đóng gói 500 | Đã giao 200 | Kiểm kê 300 ➔ Còn nợ chưa giao NOT SHIP QTY = 800 và Tồn thành phẩm STOCK = 600.

❓ Tình huống 1 (Quan trọng nhất): Vì sao đã bấm `MAKE PO` tạo đơn mua nhưng khi vào `Income status` tải file Excel nhập kho lại báo lỗi không nhận diện được PO? ▼
Nguyên nhân: Khi vừa bấm MAKE PO tại trang Purchase Order, đơn mua mới tạo đang ở trạng thái chờ STANDBY.
Cách xử lý: Tại trang Purchase Order, cuộn ngang bảng sang phải tới cột STATUS, nhấp vào chữ STANDBY (hoặc nút xanh lá INFO) và đổi trạng thái sang ORDERED. Ngay lập tức hàng chờ về sẽ hiện ở cột IN BALANCE trong Kho và bạn tải file Excel tại Income status sẽ thành công 100%!
❓ Tình huống 2: Khi nhấn `+ Create new BOM` (mở cửa sổ `GENERATE NEW BOM`) trong `Bom › List` mà không thấy tên Khách hàng (`BUYER`) hoặc tên Mã hàng (`STYLE CODE`) thì làm thế nào? ▼
Nguyên nhân: Danh sách lựa chọn trong cửa sổ GENERATE NEW BOM chỉ lấy từ các mã chuẩn đã được khai báo trước trong phân hệ CONFIG.
Cách xử lý:
• Nếu chưa thấy tên Mã hàng (STYLE CODE / STYLE NAME): Vào menu CONFIG ▶ Code (/mrp/config/code), nhìn sang bảng thứ 6 ở góc dưới bên phải là Style code ➔ bấm nút xanh lá + ADD (hoặc tải Excel bằng nút ⬆ UP) để tạo thêm mã Style và tên Style mới.
• Nếu chưa thấy tên Khách hàng (BUYER): Vào menu CONFIG ▶ Buyer (/mrp/config/buyer) ➔ bấm nút xanh lá + Add để thêm tên Khách hàng mới.
Sau khi tạo xong, quay lại trang Bom › List bấm + Create new BOM là sẽ thấy ngay!
❓ Tình huống 3: Vì sao Hợp đồng mới tạo ở `Contract Status › Active` lại không hiện ra trong ô chọn `CONT #` tại trang `Purchase Order`? ▼
Nguyên nhân: Mã Style code trong Hợp đồng đó chưa có bảng định mức BOM khớp Buyer và Color (nút BOM trong cửa sổ MANAGE ORDER báo đỏ Not match).
Cách xử lý: Vào BOM DATA ▶ List, tạo mới hoặc bấm COPY từ một BOM mẫu sang đúng cặp Buyer + Style code + Color của hợp đồng. Khi nút BOM chuyển sang màu xanh lá (Match), hợp đồng sẽ xuất hiện ngay tại Purchase Order.
❓ Tình huống 4: Làm sao để gộp nhiều nguyên phụ liệu của cùng 1 Nhà cung cấp vào chung 1 mã đơn mua `MATERIAL PO #`? ▼
• Khi tạo PO mới: Tick chọn tất cả các ô vuông ở cột SUPPLIER của các vật tư cùng Nhà cung cấp rồi bấm nút xanh lá MAKE PO một lần.
• Khi đã có sẵn PO: Bấm nút màu xanh lá ADD (ở cột ADD / DEL đầu dòng) ➔ chọn mã PO-R-... có sẵn ➔ bấm APPLY ➔ nhấp vào ô ORDER QTY của dòng vừa thêm để nhập số lượng.
